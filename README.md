# Simon and Car-game
Simon and Car-game is a game in which you must play simon whilst dodging traffic, built in python and pygame. 
It is designed that it could be played on a raspberry pi with buttons and an accelerometer to control, however by default uses keyboard input.


# Requirements
- python
- pygame

# Installation
1. Clone repository:
```
git clone https://github.com/Sammy-The-Fish/SimonAndCarGame.git
```
2. run `main.py`:
```
python main.py
```

# Controls
The keyboard inputs are:
- A: Blue, S: Green, D: Red: F: Yellow
- Arrow keys for movement
